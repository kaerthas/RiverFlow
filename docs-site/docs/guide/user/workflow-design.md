# 流程设计

## 设计器界面

流程设计器基于 LogicFlow 实现，界面分为三个区域：

- **左侧节点面板**：展示所有可用节点类型，包括内置节点和插件节点
- **中间画布区域**：拖拽式编排流程，支持连线、删除、撤销等操作
- **右侧属性面板**：选中节点后展示该节点的配置表单

## 创建流程

1. 点击「新建流程」按钮
2. 填写流程基本信息：名称、编码、触发类型
3. 从左侧拖拽 `start` 节点到画布
4. 继续拖拽其他节点，用鼠标连接节点之间的连线
5. 选中节点，在右侧面板配置参数
6. 点击「保存」或「保存并发布」

## 发布流程

- **保存**：仅保存流程定义，不发布，不影响已运行的实例
- **保存并发布**：发布新版本，旧版本自动下线，但已运行的实例不受影响

## 输入/输出映射

每个节点支持 `inputMapping` 和 `outputMapping`，用于节点间的数据传递：

```json
{
  "inputMapping": [
    { "source": "context.userId", "target": "userId" }
  ],
  "outputMapping": [
    { "source": "data.token", "target": "context.apiToken" }
  ]
}
```

## 条件分支

使用 `condition` 节点实现分支逻辑：

1. 拖拽 `condition` 节点
2. 配置 SpEL 表达式，如 `context.status == 'success'`
3. 连接不同分支到后续节点
